# Ghammas Baladi radio architecture

- **Branch playback.** Cloudflare Workers Free serves the Arabic React and TypeScript SPA and listener QR. The public Supabase station function supplies compact status and mount information. Each branch browser connects directly to the same HTTPS Icecast MP3 stream. Per-device controls and reconnection are local. Volume-locked browsers receive hardware-button guidance.
- **Manager authorization.** Supabase Auth authenticates the manager. Edge functions check allowed origins and validate the bearer. PostgreSQL enforces a restricted administrator allowlist, revision checks, publication overlap and operation reservations. Edge credentials for the station stay server-side.
- **Library and collections.** AzuraCast holds the authoritative media IDs. A revisioned library collection is an ordered array of media IDs, independent of daily and program records. The picker inserts those IDs into the destination in order and skips tracks already present. The destination saves its own flat sequence. An upload is resolved by its stable request identity, stored path, size and media readiness before insertion. The browser releases temporary preview URLs.
- **Daily workflow.** Station read-back identifies the sole enabled, sequential, unscheduled fallback. The configured daily target enables order-only writes when read-back and saved membership agree. The recovery target stays protected. The dedicated daily pointer supplies the saved working copy. Before the first save the editor starts from station read-back. Saving changes PostgreSQL only. A separate update compares the reviewed order against the station, skips already-current changes, and verifies changed order after the write. Membership and fallback selection are station-dashboard operations.
- **Program workflow.** The manager enters Amman civil time. PostgreSQL derives UTC windows and stores ordered media IDs. Saving an edit keeps verified publication intact. An Edge operation reserves the program, checks file readiness, distinct recording identity, restricted recordings and protected daily memberships, stages the owned provider playlist, checks it, enables it, and reads it back. Cancellation clears that owned playlist’s schedule and memberships. Quintastream executes playout independently of the administration UI.
- **Review boundary.** An API receipt establishes provider configuration. MP3 captures and physical listening establish playback only for their recorded intervals. Provider queue behavior can affect audible transitions. See [TEST_REPORT.md](TEST_REPORT.md).

The implementation uses the existing Cloudflare Workers Free and Supabase Free deployments and the existing Quintastream service.
